# Interactive Classroom Availability Prototype

This is the first prototype for the classroom availability project.

## Run it

Open `index.html` in a browser. No installation or server is required for this prototype.

## Included

- Five selectable floors
- Interactive room map
- Green, red, and gray room statuses
- Current-time status calculation
- Room details and daily timetable
- Room search
- Sample data only

## Next step

Replace the sample data in `app.js` with data served by a backend API. The backend can later import approved timetable data from Bakaláři and store it in a local database.
